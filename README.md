# Methylation_outlier_detection
Detection of DNA methylation outlier regions from long-read sequencing. The method uses phased DSS methylation files and candidate regions (e.g. CpG islands overlapping protein-coding genes) where methylation is tested using a sliding window analysis. There are two parts in the analysis, one haplotype-specific part where each phased file is treated independently to create the background and test for outliers, and one combined part where reads from both phases are added together. A binomial test is used to call an outlier window (with FDR correction), together with filters for coverage, minimum CpG sites, absolute deviation, standard-deviation based deviation, and interquartile range. The script produces two results files, one from the haplotype-specific part and one from the combined part.
